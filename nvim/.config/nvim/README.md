# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

`<leader>gs` abre Neogit; reemplaza el atajo de Git Status de Snacks Picker de LazyVim.

NvimTree se abre automáticamente al iniciar Neovim; `<leader>e` lo alterna.
El ancho inicial del árbol es de 30 columnas; si lo redimensionás, conserva ese ancho
durante la sesión aunque abras archivos desde NvimTree.
También muestra archivos ignorados por `.gitignore`; los archivos ocultos se muestran según `filters.dotfiles`.
